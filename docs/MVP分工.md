## 1. 下周五什么叫「跑通」

一条线能当众点完，才算 MVP：

```text
打开试用链接
  → 临床助手：问「维吾尔族 + 华法林 + 出血」
  → 看见存量 / 强弱 / 出处 / 边界（或明确说材料不足）
  → 文献速查：能按分类找到同一条，点开看出处
  → 材料少：到论坛发一帖（不写病历；帖子不是证据）
  → 科研助手：问「这题做不做」（只对照入库文献，不数帖子）
  → 给出跟 / 不跟 / 再等等（声明不替代立项）
  → 论坛：医生帖科研能看见；助手被要求「按帖子回答」时拒绝
```

对应验收：**A1–A6 必须过**。A7 空态、A8 脱敏能做更好，来不及就先在发帖处写清「不写姓名、住院号」。

本期明确不做：真接权威机构接口、大众问答、处方/诊断、论坛写回文献库、完整登录后台。

## 2. 张璨 · 文献（来源、分类、查找）

你交的是 **全组共用的底座**。何权的助手、张鸣的论坛对照，都读你这一套，不能另做一份互相矛盾的库。

### 你要完成

1. **来源（示意即可）**  
   每条文献写清：从哪类公开材料来、题名或编号、适用边界。不必真对接机构，但必须能追溯，不能写成「网上看到的」。
2. **分类**  
   按需求文档四类落库：流病·患病率 / 流病·危险因素 / 遗传·变异 / 药物基因组。  
   演示题目在药基组或流病里至少各能查到，并允许「某一类还没有」的空态。
3. **怎么查找**  
   文献速查可按关键词、民族、类型筛选；点进详情能看到结论摘要、出处、边界；可收藏。

### 你交什么（目录）

只改 **`src/literature/`**：

| 文件 | 做什么 |
| --- | --- |
| `data/entries.js` | 条目表。字段：民族、主题、类型、结论摘要、出处、适用边界。≥6 条，至少 2 条可被助手 cite |
| `data/shelves.js` | 四类 id 不要改（prev / risk / geno / pgx） |
| `js/search.js` | `searchLiterature` / `getLiterature` |
| `js/pages.js` | `MM.renderSearchPage`、`MM.renderLitDetail`：筛 → 列表 → 详情 → 空态 |
| `css/search.css` | 只放速查样式 |

样例可从 `demo/dual-agent/index.html` 的 `ENTRIES` 迁过来，但演示题要补上维吾尔族 × 华法林。不要改 `src/agents/`、`src/forum/`、`src/app/`。

### 怎样算你这块过

打开文献速查，用「维吾尔族 / 华法林」能找到条目，点开看出处和边界；切到「还没有文献」的分类有空说明。

### 你不要做

不要做 Agent 对话逻辑，不要做论坛。页面外壳、顶栏切换交给张鸣接。

### 依赖

## 3. 何权 · 两个 Agent

你交的是 **两种问法、同一库**。临床助手给医生对照「现在知道多少」；科研助手给科研对照「做不做」。都 **只引用张璨的入库文献**。

### 你要完成

**临床助手**

- 用户说民族 + 病/药/现象 → 检索文献库 → 回复存量、强弱、出处、边界。
- 材料不足要直说，不许编造成确定结论。
- 问「怎么治 / 开什么药 / 改剂量」→ 拒绝，说明只做证据对照。
- 可开始新对话、看历史（有空态即可）。
- 证据少时 **引导去论坛发帖**（不写病历）。医生不用在助手里上传观察。科研靠论坛了解现场。

**科研助手**

- 问「有没有人做过 / 这题做不做」→ **只对照入库文献条数**。
- 给出跟 / 不跟 / 再等等，并写明不替代立项、伦理。不把帖子次数当证据。
- 可看研判记录或一键对照报告（能复制或能展示即可）。

**隔离（必须做）**

- 用户说「按论坛某帖回答」→ 拒绝。
- 回复里的出处只能是文献编号/题名，不能是帖子。

### 你交什么（目录）

只改 **`src/agents/`**：

| 文件 | 做什么 |
| --- | --- |
| `clinic/prompt.js`、`clinic/agent.js` | 临床提示词 + `answerClinic` |
| `research/prompt.js`、`research/agent.js` | 科研提示词 + `answerResearch` |
| `shared/parse.js` | 抽民族 / 病药 / 现象 |
| `shared/refuse.js` | 拒诊疗、拒「按帖子回答」 |
| `js/pages.js` | `MM.renderClinicHome`、`MM.renderResearchHome` |
| `css/agents.css` | 只放助手页样式 |

另外准备 **3 组能点的问法**（医生 2 句、科研 1 句）。不要改 `src/literature/data/`，条目问张璨；不要改 `src/forum/`。

### 怎样算你这块过

临床问华法林能出带出处的对照或「不足」；科研问做不做能出带边界的参考；故意问诊疗、故意要论坛当证据，两次都拒绝。

### 你不要做

不要自己再找一套文献。分类和条目以张璨为准。论坛列表、发帖页交给张鸣。

### 依赖

等张璨的字段和样例。现场问题走张鸣的论坛，何权的 Agent **不要**做上传观察。
