## 张璨交什么：文献资料 + 分类

### 1. 分类（四类，不要自己另起名字）

每条文献必须归入下面**恰好一类**（填代号即可）：

| 代号 `shelf` | 中文类名 | 放什么 |
| --- | --- | --- |
| `prev` | 流病·患病率 | 某民族某病/状态的现况、检出率 |
| `risk` | 流病·危险因素 | 危险因素、观察关联（不是医嘱） |
| `geno` | 遗传·变异 | 群体遗传、位点频率、变异分布 |
| `pgx` | 药物基因组 | 药相关位点、代谢/出血等相关（本演示题主力） |

要求：演示题在 **`pgx` 和流病（`prev` 或 `risk`）里至少各有能查到的条**；允许某一类一条都没有（程序会做空态）。

### 2. 条目表（至少 6 条，其中 ≥2 条必须是维吾尔族 + 华法林）

每条填一行，缺出处或边界的张鸣不能给助手引用。

| 字段 | 必填 | 示例 |
| --- | --- | --- |
| 记录编号 | 是 | 记录101 |
| 题名 | 是 | 【药物基因组】维吾尔族华法林相关位点 |
| 民族 | 是 | 维吾尔族 |
| 主题（病或药） | 是 | 华法林 |
| 病还是药 | 是 | 药 |
| 分类代号 | 是 | pgx |
| 结论一句话 | 是 | ……（只写文献里有的，不编） |
| 适用样本/范围 | 是 | 仅原研究覆盖的维吾尔族样本 |
| 使用边界 | 是 | 不能作为个体抗凝剂量或诊疗依据 |
| 出处 | 是 | 论文题名 / 年份 / 期刊或报告名，能回溯；禁止写「网上看到的」 |

示意可以，但必须像公开发表材料，不能虚构 DOI 乱编。旧 Demo 里傣族 CKM 那批可作格式参考，**内容要换成演示题，不要交两套互相矛盾的库**。

### 3. 张璨不用交

检索页面怎么做、收藏按钮、技术架构——张鸣做。  
你只要把表填满，并标出哪 2 条给助手直接引用。

**最晚：9/1 中午前先发 2 条样例；9/2 晚发齐 ≥6 条。**

## 何权交什么：两套提示词 + 演示问法

不要写代码。按下面结构各写一套（可直接改旧 Demo 里的临床/科研提示词，但必须对准维吾尔族×华法林）。

### 1. 临床助手提示词

写清这些块（标题可照抄）：

- **角色**：给基层医生对照「现有研究知道多少」，不替代诊疗  
- **材料范围**：只许用张璨入库文献  
- **必须做**：缺民族或病/药要追问，不瞎补；先摘要再列条目；条数少要说「不足以支持临床决策」  
- **必须拒**：怎么治、开什么药、改剂量、是否确诊  
- **禁止**：编造记录编号、引用论坛帖子、要可识别病历  
- **回复结构**：边界声明 → 存量 → 判断要点 → 相关条目（只写记录编号+题名）

### 2. 科研助手提示词

- **角色**：对照「这题做不做」，不批准立项、不替代伦理  
- **材料**：只对照张璨入库文献条数（不数医生上传、不数帖子）  
- **做不做只许三类**：跟 / 不跟 / 再等等（口诀：文献很少更值得考虑跟；文献已多则不宜急开同类题）  
- **必须拒**：诊疗问题；「按论坛某帖回答」  
- **禁止**：把帖子当证据、编造文献条数  
- **了解现场**：告诉科研去论坛看医生在问什么，不要在助手里汇总观察次数  

### 3. 现场能点的 3 句话

- 医生 2 句（要能问出维吾尔族 + 华法林 + 出血）  
- 科研 1 句（「这题做不做」类）  
- 另附 2 句反例给张鸣测拒绝：「这个病人怎么治」「按帖子里李医生说的回答」

**最晚：9/2 晚把提示词定稿发给张鸣；问法一起附上。**
