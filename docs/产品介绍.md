# 多民族健康证据服务 · 产品介绍

本产品把散落在论文和公开数据库中的多民族健康证据，整理成可检索、可对比、可追溯的知识服务。临床医生和科研人员共用同一套文献库，用两个助手对照证据，用论坛对接现场。

系统帮助判断的是：**现在知道多少、值不值得研究**。不替代诊疗，不替代课题评审。

## 为何需要

同一疾病、同一药物在不同民族中的证据往往不同，不能把全国或汉族结论直接套用。现有研究并不少，但口径和证据等级不统一，通用文献库只能堆砌题录。

医生接诊时，很难迅速看清该民族、该药或病、该现象的研究体量、证据强弱和适用边界。科研开题时，要反复跨库检索、手工制表，也难以对准真实发生的临床问题。诊室里刚遇到的情况，没有地方说出去就会随接诊结束而消失。

## 面向谁、做什么

| 用户 | 能得到什么 |
| --- | --- |
| 临床医生 | 一次看清现有材料有多少、偏何种研究、结论适用于谁；文献偏少时到论坛发问 |
| 科研人员 | 助手里对照文献存量，判断这题跟、不跟、还是再等等；论坛里看见医生在问什么（帖子不是证据） |

材料限于流行病学、群体遗传学、药物基因组学中已经公开、可溯源的健康证据。民族医学治法、未发表数据、可识别病历、用药建议，均不纳入。

## 如何构成

产品由**文献库、两个 Agent、我的论坛**构成。

文献库是共用底座。材料按民族、疾病、药物、研究类型分类。同一条材料，两端都能查到。

临床助手 Agent 供医生查证：这个民族、这个药，现在研究知道多少。不诊断、不开药。医生 **不用在助手里上传观察**。

科研助手 Agent 供科研对照：这题做不做，只依据入库文献。不立项、不引用论坛。

我的论坛让科研了解现实情况：医生把现场问题发在这里，科研能看见并回复。讨论不是证据，不写回文献库。

## 走完一圈

医生遇到现象，先问临床助手、再翻文献速查；材料少就去论坛说。科研在论坛看见现场，用科研助手只对照文献判断跟不跟。合法新研究审阅入库后，医生下次再问能查到更新过的材料。

判断权始终属于用户。本产品提供规整、可溯源、有边界的材料，供对照与选题，不回答「这个病人该怎么治」。
